# ucat — «Помощь активисту» (Казань)

**Java 17 / Maven-прототип** информационной системы раннего обнаружения проектов, решений, общественных обсуждений и работ в интересующих горожанина территориях. Версия 0.1.0. Основная идея: объединять сигналы о предстоящих городских изменениях и уведомлять активиста заблаговременно.


### Линейные объекты и истории проектов (21.10.2026)

Вкладка **«Проекты»** позволяет вручную объединять официальные документы в хронологию конкретного проекта. Для дорожных актов извлекаются границы вида «от улицы А до улицы Б», а также отдельные номера домов, километровые отметки и конкретный этап проекта.

После нажатия **«Улицы»** для малого полигона сохраняется OSM-граф соседних дорог. `RoadCorridor` проверяет пересечения с двумя поперечными улицами по общим OSM-узлам и рисует **предполагаемый** участок пунктиром. Все оценки остаются на ручную проверку; это не контур из проектного документа.

Архивный пилот для Несмелова/Кировской дамбы: [`docs/LINEAR_WORK_PILOT.md`](docs/LINEAR_WORK_PILOT.md), [`examples/kazan-road-archive-pilot.json`](examples/kazan-road-archive-pilot.json). Для геометрической части офлайн-теста используются синтетические дорожные сегменты, не якобы фактический OSM-снимок.

## Для чего это приложение

Активист рисует на карте многоугольники интересующих участков и задаёт дополнительные слова (улицы, топонимы, кадастровые номера). Система показывает события в ленте и различает три ситуации:

- `MATCH` — у события есть *точная установленная вручную точка*, попадающая внутрь наблюдаемого полигона (демонстрационный уровень);
- `HINT` — геометрия неизвестна, но совпали слова из документа и территории. **Это подсказка, а не доказательство пространственного пересечения**;
- `UNLOCATED` — координат нет и совпадений по словам нет. Такое событие всё равно показывается: оно может затрагивать территорию;
- `OUTSIDE` — известная точка не попадает ни в один полигон.

В полноценной версии точка события должна заменяться геометрией работ (`Point`, `LineString`, `Polygon`/`MultiPolygon`) из документа с указанием источника геопривязки и её точности.

## Запуск (Windows / Linux / macOS)

Нужна Java **17 или новее**. Maven нужен, чтобы пересобрать код; готовый JAR запускается без Maven.

В корне репозитория:

```bash
mvn package
java -jar target/pomosh-aktivistu-0.1.0.jar
```

Открыть **http://127.0.0.1:8080**.

Также отдельно поставляется уже собранный `pomosh-aktivistu-0.1.0.jar`; его можно запускать командой `java -jar pomosh-aktivistu-0.1.0.jar`.

Windows: `run.bat` запускает JAR из `target/` или предлагает сначала выполнить `mvn package`.

Данные сохраняются **локально** в `./data/activist.json` (JSON). Чтобы использовать каталог в другом месте, задайте `ACTIVIST_DATA_DIR`.

Пример Linux:

```bash
ACTIVIST_PORT=8081 ACTIVIST_DATA_DIR=/srv/activist-data java -jar target/pomosh-aktivistu-0.1.0.jar
```

PowerShell:

```powershell
$env:ACTIVIST_PORT='8081'
$env:ACTIVIST_DATA_DIR='C:\activist-data'
java -jar .\target\pomosh-aktivistu-0.1.0.jar
```

Для запуска без демонстрационных примеров: `ACTIVIST_DEMO=false` (или `$env:ACTIVIST_DEMO='false'`). Если уже создан каталог `data`, демо-записи не исчезают автоматически: создайте новый каталог либо скройте их через карточку события, чтобы они не мешали ленте.

### Что работает в прототипе

1. Отображение карты Казани (Leaflet + OpenStreetMap; нужна сеть для внешней библиотеки и тайлов).
2. Рисование и сохранение пользовательских многоугольников по нажатию на карту, отдельные названия и текстовые метки.
3. Лента событий, стадии (подготовка, обсуждение, закупка, утверждение, работы), фильтры и поиск.
4. Ручное добавление событий, подтверждение точки на карте, проверка принадлежности к одному или нескольким полигонам.
5. Обработка полигонов в GeoJSON EPSG:4326, включая отверстия и MultiPolygon, вычисление point-in-polygon.
6. Защита от повторного сохранения события с идентичной ссылкой; `firstSeen` — момент первого добавления в **нашу** базу.
7. Сохранение заметок, установленного вручную крайнего срока, статуса просмотра; скрытие ложных/тестовых событий с возможностью вернуть их в ленту.
8. Фоновый **экспериментальный** HTML-поиск публикаций на нескольких официальных площадках и кнопка проверки.
9. По желанию — Telegram-сводка только о *новых событиях, обнаруженных экспериментальной проверкой*, после каждого прохода.
10. Экспорт локальных данных в JSON; программный пакетный импорт до 200 событий за один запрос.

### Новые дорожные источники (KZN / ЕИС / Минтранс РТ)

В прототипе подключены **экспериментальные** сборщики официальных публикаций (дополнительно реализованы SOAP ЕИС и PDF-коннекторы; см. ниже): муниципальный реестр правовых актов `kzn.ru`, анонсы выпусков в новостях `kzn.ru`, главная страница сетевого издания `docskzn.ru`, два документальных раздела Минтранса Татарстана, республиканские дорожные новости, публичные результаты поиска ЕИС и локальная папка с выгрузками закупок.

- **Постановления Казани.** Из видимых заголовков муниципального выпуска извлекается **каждое постановление отдельно**, с собственным `externalId`. Номер и дата акта сохраняются отдельно от `publishedAt`. Один выпуск может содержать много актов, и общая ссылка на выпуск не должна удалять их как дубли.
- **Дорожные закупки.** Ищем строительные работы, ремонт, реконструкцию, проектирование, изыскания и содержание автомобильных дорог/городских улиц/путепроводов. Поиск не ограничен одним нацпроектом или ведомственным заказчиком. Однако **включаются лишь кандидаты с текстовым указанием Казани именно в предмете/адресе работ**, а не в юридическом адресе заказчика. Требуется подтверждение, что дорога находится внутри границ города.
- **Минтранс РТ.** Отслеживаются документы о дорожных работах, включая постановление КМ РТ от 22.01.2026 №30 «О дорожных работах ... на 2026–2028 годы». Если в заголовке нет Казани, событие хранится с `locationScope=REGIONAL_REVIEW`: необходимо открыть PDF и проверить, не включает ли приложение казанские объекты. Такие записи **не считаются подтверждённым пересечением с полигоном**.
- **Поля происхождения.** `externalId`, `source`, `documentKind`, `authority`, `program`, `issuedAt`, `publishedAt`, `firstSeen`, `locationScope`, `requiresReview`; `position` по умолчанию отсутствует. Неизвестная программа финансирования записывается как неизвестная, не приписывается федеральной программе автоматически.

**ЕИС может блокировать публичный HTML-поиск**, а сервисы отдачи машиночитаемых документов требуют отдельной проверки требований на стороне ЕИС. Чтобы не зависеть только от HTML, приложение умеет при каждом сканировании считывать локальные CSV/XML/ZIP-выпуски из папки `ACTIVIST_EIS_INBOX`. Это не обход ограничений сайта и не автоматическая выгрузка из ЕИС: файлы нужно получить законным способом и положить в папку. Стандартизованный пример CSV приведён в `examples/eis-sample.csv`, технические детали — `docs/ROAD_MONITORING.md`. Добавлен **опциональный экспериментальный SOAP-клиент getDocsIP**; без пользовательского токена он отключён. Инструкции по настройке, ограничения и проверенные реквизиты протокола — в `docs/EIS_AND_PDF_RESEARCH.md`.

Linux:

```bash
export ACTIVIST_EIS_INBOX=/srv/ucat/eis-inbox
java -jar target/pomosh-aktivistu-0.1.0.jar
```

Windows PowerShell:

```powershell
$env:ACTIVIST_EIS_INBOX='C:\ucat\eis-inbox'
java -jar target/pomosh-aktivistu-0.1.0.jar
```

Создайте каталог заранее. Кнопка «Проверить источники» запускает импорт. Обновления HTML и документы могут не извлекаться из-за блокировки доступа, смены разметки или публикации только в PDF. **Нельзя считать эту версию полноценным непрерывным мониторингом юридически значимых сроков.**

### Исследование ЕИС SOAP и приложений к постановлениям (2026-10-20)

Внесены экспериментальные адаптеры к **официальному SOAP-сервису выдачи ЕИС getDocsIP** и к **PDF-приложениям актов Казани / Кабинета министров Татарстана**. Источники PDF: `pravo.tatarstan.ru/kazan/ispolkom`, `pravo.tatarstan.ru/npa_kabmin/post` и программа дорожных работ на сайте Минтранса РТ.

Для ЕИС зарегистрируйтесь в личном кабинете получателя машиночитаемых данных (физическое лицо) через https://zakupki.gov.ru/pmd/auth/welcome, затем задайте переменную `ACTIVIST_EIS_TOKEN` **только в настройках сервера/окружения**, не публикуйте токен в Git. Официальный сервис в 2026 году использует SOAP и выдаёт архивы машиночитаемых документов; полный перечень типов сверяйте с актуальным XSD.

```bash
export ACTIVIST_EIS_TOKEN='ТОКЕН_ИЗ_ЛИЧНОГО_КАБИНЕТА'
export ACTIVIST_EIS_TYPES='epNotificationEF2020,epNotificationEZK2020'
# необязательно: импорт одной исторической даты
# export ACTIVIST_EIS_DATE='2026-10-19'
# необязательно: каталог заранее скачанных приложений
# export ACTIVIST_ANNEX_INBOX='/path/to/pdf-documents'
java -jar target/pomosh-aktivistu-0.1.0.jar
```

При отсутствии `ACTIVIST_EIS_DATE` опрашиваются **сегодня и вчера по московскому времени**. По умолчанию (если `ACTIVIST_EIS_TYPES` не задан) запрашивается только `epNotificationEF2020`: это **НЕ все закупки**. Для проектов, заказчик которых зарегистрирован за пределами Татарстана, выборка региона заказчика `16` недостаточна. Способ наращивания охвата описан в [техническом исследовании](docs/EIS_AND_PDF_RESEARCH.md).

Ограничения: SOAP-клиент и отбор ссылок на PDF ещё не проверены с живыми сайтами в этой среде, архивы ограничены 30 МБ, PDF — 32 МБ и 180 страниц. Текст распознаётся только там, где PDF содержит текстовый слой. Все извлечённые строки — предварительные сигналы, **не подтверждённые координаты и не гарантированный полный перечень объектов**.

### Что ещё НЕ работает автоматически

- Достоверная и полная выгрузка `dispute.kzn.ru`, `pravo.tatarstan.ru`, `kzn.ru`, `dvor.tatar`. Их видимые страницы и реальные источники установлены, но **HTML-адаптеры не проходили онлайн-интеграционное тестирование** и могут не распознать разметку или упереться в JavaScript / защиту / региональные ограничения. UI показывает статус каждой попытки.
- **Сквозное подтверждение работы SOAP с реальным токеном ЕИС**: добавлен клиент `getDocsIP` для физического лица, но запросы проверены на макетах, не на реальном сервисе. По умолчанию выгружается только один подтверждённый тип извещения 44-ФЗ `epNotificationEF2020`. Покрытие всех закупок 44/223-ФЗ и заказчиков из других регионов не гарантировано.
- **PDF/OCR:** подключён разбор текстового слоя PDF (PDFBox 3), с выделением кандидатов на дорожные объекты Казани. Но полнота таблиц, графики, планов, сканов без текстового слоя и точной геометрии пока не подтверждена. Для таких файлов требуется OCR или ручная проверка.
- Автоматическая геокодировка адресов/кадастровых номеров; полная геометрия дорожных участков и планировочных зон.
- Автоматическое вычисление правового срока представления замечаний, законности участия или подача замечаний от имени активиста.
- Объединение публикаций одной стройки в одну историю (`project_id`). Пока каждая уникальная URL — отдельная запись.
- Многопользовательский режим, учетные записи, публичный HTTPS-деплой.

**Не использовать это приложение как единственный способ узнавать о юридически значимых сроках.** Прототип может пропустить публикации. Даты публикации и закрытия обсуждений нужно сверять с официальной карточкой.

## Уведомления в Telegram

Создайте бота через Telegram и получите `chat_id`, затем задайте переменные среды (не в git-репозитории):

```bash
export ACTIVIST_TELEGRAM_TOKEN='...'
export ACTIVIST_TELEGRAM_CHAT_ID='...'
export ACTIVIST_SCAN_HOURS=6
java -jar target/pomosh-aktivistu-0.1.0.jar
```

На Windows PowerShell используются `$env:ACTIVIST_TELEGRAM_TOKEN='...'` и `$env:ACTIVIST_TELEGRAM_CHAT_ID='...'`.

Повторная проверка проводится каждые 6 часов (изменяется `ACTIVIST_SCAN_HOURS`), первый автоматический запуск — через 2 минуты. При этом кнопка «Проверить источники» запускает проверку немедленно. Telegram отправляет *сводку на завершении* проверки, не уведомление на каждую запись. Дата `firstSeen` — дата обнаружения приложением, **не** день выхода акта.

Если приложение закрыто, ни проверки, ни уведомления не выполняются. Для постоянного мониторинга запускать как отдельный Java-сервис на постоянно работающем ПК/VPS. Для надёжного мониторинга источников потребуется более качественный интеграционный слой.

## Права и безопасность

- По умолчанию сервер доступен **только с этого компьютера** (`127.0.0.1`), **авторизации нет**. Не выставляйте напрямую в Интернет. `ACTIVIST_BIND=0.0.0.0` без HTTPS и авторизации опасен.
- Никаких персональных данных активиста для начала работы не требуется.
- Сведения о территориях и заметках локальны. Telegram получает заголовки уведомлений только если явно настроен бот.
- Внешние запросы HTML-проверок ограничены зашитыми в код HTTPS-источниками, есть таймауты, ограничение размера страницы и паузы. Никаких попыток обходить CAPTCHA/авторизацию.
- Уважайте правила доступа к государственным источникам. Перед публичным развертыванием согласуйте правила машинного чтения и частоту опроса.
- Браузер получает Leaflet с CDN и тайлы OpenStreetMap при загрузке карты; соблюдайте [OSM tile usage policy](https://operations.osmfoundation.org/policies/tiles/). Для продакшена предусмотрите управляемого поставщика тайлов.
- Не используйте публичный Nominatim для массовой геокодировки: у него ограничения запросов и обязательное кеширование ([политика](https://operations.osmfoundation.org/policies/nominatim/)). В прототипе геокодировка намеренно не добавлена.

## HTTP API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/health` | Статус процесса |
| GET/POST | `/api/areas` | Список/создание областей GeoJSON |
| DELETE | `/api/areas/{id}` | Удалить область |
| GET/POST | `/api/events` | Список событий с актуальным статусом / создать событие |
| PATCH | `/api/events/{id}` | `position`, `seen`, `dismissed`, `note`, `deadline` |
| POST | `/api/import` | Импорт `{"events":[...до 200...]}` |
| GET | `/api/sources` | Состояние HTML, SOAP и PDF-адаптеров |
| POST | `/api/scan` | Запуск проверки в отдельном потоке |
| GET | `/api/export` | Резервная копия JSON |

Пример ручного импорта события (важно: `[lon,lat]`, **не** `[lat,lon]`):

```bash
curl -X POST 'http://127.0.0.1:8080/api/events' \
  -H 'Content-Type: application/json' \
  -d '{"title":"О подготовке проекта планировки по ул. Примерная", "source":"MANUAL", "url":"https://example.org/document-123", "position":[49.10,55.80]}'
```

Если координаты неизвестны, `position` **не указывают**. Нельзя подставлять географический центр Казани или случайную точку улицы для создания видимости точности.

## Разработка и тесты

Код — Java 17, PDFBox 3.0.7 для чтения PDF и Maven Shade для сборки исполняемого JAR со всеми библиотеками. Для небольшого одно-пользовательского прототипа использован `HttpServer` из JDK вместо Spring Boot; Maven собирает JAR с `Main-Class`.

- `src/main/java/.../ActivistApp.java` — HTTP API, отдача веб-ресурсов, запуск;
- `Store.java` — JSON-постоянное хранение и метки релевантности;
- `Geo.java` — проверка точки в GeoJSON-многоугольнике;
- `Classification.java` — первичное определение стадии;
- `Discovery.java` — планировщик сбора источников;
- `EisSoapClient.java` — опциональный клиент getDocsIP (авторизация токеном ЕИС);
- `RoadAnnex.java` — чтение текстового слоя PDF и выделение кандидатов с указанием страницы;
- `Notifier.java` — опциональная Telegram-сводка;
- `src/main/resources/web` — веб-интерфейс на Vanilla JS + Leaflet;
- `src/test/java/ru/activisthelp/SmokeTest.java` — автономные smoke-тесты.

Запустить автономные тесты без JUnit (после `mvn package`):

```bash
javac --release 17 -encoding UTF-8 -cp target/classes -d target/test-classes src/test/java/ru/activisthelp/SmokeTest.java
java -ea -cp target/classes:target/test-classes ru.activisthelp.SmokeTest
java -ea -cp target/classes:target/test-classes ru.activisthelp.RoadSourcesTest
```

Для Windows вместо `:` в `-cp` используйте `;`.

Планы развития и реальные источники: `docs/ARCHITECTURE.md` и `docs/SOURCES.md`.


## Географический индекс полигонов (новое)

Для каждой зоны в интерфейсе есть кнопки **«Улицы»** (однократное обогащение из Overpass/OSM)
и **«Участки»** (импорт кадастровых идентификаторов `.geojson`, `.json`, `.txt`, `.csv`).
После импорта `GET /api/events` показывает не только пользовательские ключевые слова, но и
признаки `CADASTRAL`/`STREET` с объяснениями. Карточка события предлагает кандидатов
на связь с другими актами, приложениями и закупками (`GET /api/related?eventId=...`).

**Только подсказки:** совпадение кадастрового номера или названия улицы не подтверждает,
