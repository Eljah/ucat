# Дорожный мониторинг Казани: адаптеры и пределы достоверности

Действует для MVP `ucat`. Технология — Java 17 и Maven, без новых внешних зависимостей. Реальная работа сайтов и машинных API требует испытаний на сервере с доступом в интернет. В тестах используются искусственные HTML/XML/CSV фрагменты.

## Каналы

1. **KZN_ACTS** — актуальный муниципальный реестр актов `kzn.ru/nayti-dokument/munitsipalnye-pravovye-akty-i-inaya-ofitsialnaya-informatsiya/`. Читает видимые заголовки и ссылки.
2. **KZN_BULLETINS** — страница новостей `kzn.ru/meriya/press-tsentr/novosti/`, отбирает выпуски с заголовками `budet-opublikovano-setevoe-izdanie-*`, разбивает пары `<p><b>Постановление ... №...</b></p><p>О ...</p>` на отдельные события. Один URL выпуска может дать десятки `externalId`. При изменении HTML это может перестать работать.
3. **DOCSKZN** — сетевое муниципальное издание `docskzn.ru`. Читает только непосредственно видимые заголовки документов, без извлечения PDF.
4. **RT_ROADPLAN** — постановления Кабинета министров РТ на сайте Минтранса. Специально не отбрасывает республиканские планы без слова «Казань», поскольку объекты города могут быть внутри приложения.
5. **RT_ORDERS / RT_ROAD_NEWS** — нормативные акты и заголовки новостей Минтранса.
6. **EIS_ROADS** — поиск трёх типов дорожных закупок через публичные HTML-страницы `zakupki.gov.ru`. Разметка сайта и свободный доступ к поиску не гарантированы; при блокировке источник показывает ошибку, а не фиктивный нулевой результат.
7. **EIS_INBOX** — чтение локальных `.csv`, `.xml`, `.zip` до 6 МБ из каталога `ACTIVIST_EIS_INBOX`. Подходит для ручной выгрузки из ЕИС и законно полученных открытых файлов. Не включает получение файлов из ЕИС.

## Фильтрация дорожных закупок

`roadWorks(title)` требует тему дорожного строительства, ремонта, проектирования, содержания или реконструкции. `candidateKazan(title, workAddress)` требует упоминания Казани **в объекте/месте работ**, не в заказчике. Явно указанный иной город без Казани отбрасывается.

Контракт, связанный с Казанью как начальной или конечной точкой регионального маршрута, может оказаться **за городской чертой**. Значение `KAZAN_MENTION` — только текстовая подсказка, не геометрическое подтверждение. Никакие найденные HTML-записи автоматически не переводятся в `MATCH` с пользовательским полигоном. Без установленных координат или контура UI показывает `UNLOCATED`/`HINT`.

Программа финансирования не обязательна для включения закупки. Если в объявлении не названа конкретная федеральная программа, поле `program` остаётся пустым; нельзя автоматически приписывать закупку нацпроекту «Инфраструктура для жизни».

## CSV

Поддерживается **нормализованный** CSV со столбцами (англ. или часть русских аналогов):

```csv
notice_number;title;work_address;customer;published_at;program;url
0123456789012345678;Реконструкция автомобильной дороги;город Казань, улица Несмелова;Заказчик;2026-04-23;Инфраструктура для жизни;https://zakupki.gov.ru/epz/order/extendedsearch/results.html?searchString=0123456789012345678
```

Пример **синтетический**; не выдавать пример за настоящую закупку. Схема официальной выгрузки ЕИС может отличаться: в таком случае сначала потребуется привести её к CSV выше. XML-парсер пытается читать общие имена полей ЕИС в именованных пространствах; гарантировать совместимость со всеми разновидностями сообщений ЕИС нельзя. ZIP обрабатывается без распаковки на диск.

## Дедупликация и даты

- `externalId` — стабильное уникальное значение в рамках `source`; при его наличии события с одним URL сохраняются отдельно. Для постановлений идентификатор строится по реквизитам заголовка.
- Если в акте написано «от 23.04.2026», это `issuedAt` (дата подписания), **не** `publishedAt`. Для заголовков HTML без даты официальной публикации поле `publishedAt` пустое.
- `firstSeen` появляется при первой записи в локальную базу. Отсутствие вновь найденных событий может означать как отсутствие публикаций, так и смену HTML/403.

Нужны мониторинг ошибок, хранилище исходников и отдельные тесты доступности каждого ведомственного ресурса.
